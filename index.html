SQL Базы: Основы

10 самых важных и простых запросов для старта

🔍

SELECT

Выбирает данные из таблицы. Это самый базовый запрос, который позволяет получить информацию.

SELECT * FROM users;
📂

FROM

Определяет, откуда будут взяты данные. Обычно используется с SELECT для указания таблицы.

SELECT * FROM users;
🎯

WHERE

Фильтрует строки. Позволяет выбрать только те записи, которые соответствуют условию.

SELECT * FROM users WHERE age > 18;
📊

ORDER BY

Сортирует результаты. Позволяет отсортировать строки по возрастанию или убыванию.

SELECT * FROM users ORDER BY age DESC;
🔒

LIMIT

Ограничивает количество возвращаемых строк. Используется для получения первых N элементов.

SELECT * FROM users LIMIT 10;
🔗

JOIN

Соединяет таблицы на основе общих колонок. Позволяет получить данные из нескольких таблиц.

SELECT * FROM users JOIN orders ON users.id = orders.user_id;
📁

GROUP BY

Группирует строки по определенным колонкам. Часто используется с COUNT и SUM.

SELECT department, COUNT(*) FROM employees GROUP BY department;
📋

HAVING

Фильтрует группы. Используется после GROUP BY, так как работает с группами, а не со строками.

SELECT department FROM employees GROUP BY department HAVING COUNT(*) > 5;
🧩

DISTINCT

Уникализует значения. Возвращает только разные значения из выборки.

SELECT DISTINCT department FROM employees;
➕

INSERT

Добавляет новую запись в таблицу. Создает строку с указанными значениями.

INSERT INTO users (name, email) VALUES ('Иван', 'ivan@example.com');
