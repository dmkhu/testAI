SQL Базовые Запросы

10 самых важных и простых запросов для начинающих

SELECT * FROM table_name;

Самый простой запрос. Возвращает все колонки и значения из выбранной таблицы.

SELECT * FROM users;

SELECT column_name FROM table_name;

Вызывает только конкретную колонку из таблицы, игнорируя все остальные поля.

SELECT name FROM users;

SELECT column_name1, column_name2 ... FROM table_name;

Вызывает несколько колонок из одной таблицы одновременно.

SELECT name, age FROM users;

SELECT column_name1, column_name2 ... FROM table_name WHERE condition;

Фильтрует строки в таблице. Условие (WHERE) должно быть выражением сравнения.

SELECT name FROM users WHERE age > 18;

SELECT column_name1, column_name2 ... FROM table_name GROUP BY group_column;

Группирует строки по определенным колонкам и возвращает статистику для каждой группы.

SELECT department, COUNT(*) FROM employees GROUP BY department;

SELECT column_name1, column_name2 ... FROM table_name ORDER BY sort_column;

Отсортирует строки в таблице по указанному столбцу. По умолчанию сортировка идет по возрастанию.

SELECT name FROM users ORDER BY age DESC;

SELECT column_name1, column_name2 ... FROM table_name LIMIT n;

Возвращает только первые n строк из таблицы. Используется для ограничения количества данных.

SELECT name FROM users LIMIT 10;

SELECT column_name1, column_name2 ... FROM table_name HAVING condition;

Фильтрует строки после группировки (только для SELECT). Используется вместо WHERE для сложных условий.

SELECT department, COUNT(*) FROM employees GROUP BY department HAVING COUNT(*) > 5;

INSERT INTO table_name (column1, column2) VALUES (value1, value2);

Добавляет новую строку в таблицу. Если колонка уже существует, значение автоматически заполняется.

INSERT INTO users (name, email) VALUES ('Иван', 'ivan@example.com');

UPDATE table_name SET column_name = value WHERE condition;

Изменяет значения в существующих строках таблицы. Условие (WHERE) определяет, на какую строку применить изменения.

UPDATE users SET age = 25 WHERE name = 'Иван';
